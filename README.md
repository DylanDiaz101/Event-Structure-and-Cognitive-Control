# WIP: Event Structure and Cognitive Control - Virtual AX-CPT

## Overview
This WIP project involves the development of a virtual reality version of the **AX Continuous Performance Task (AX-CPT)** to examine the relationship between event structure and cognitive control.

**Windows:**  
```
C:\Users\yourName\AppData\LocalLow\DefaultCompany\Event-Structure-and-Cognitive-Control
```

- Ensure you have appropriate permissions to access the data folder.
